# macOS: «файл повреждён и его не удалось открыть»

EHOT Launcher собирается в CI на GitHub Actions и **не имеет платной подписи Apple Developer ID и нотаризации**
(она стоит $99 в год; программа не подключена). Поэтому macOS при первом открытии приложения, скачанного из интернета,
блокирует его и показывает сообщение «EHOT Launcher is damaged and can't be opened» / «файл повреждён…».

Сама сборка при этом целая и рабочая. Это стандартное поведение Gatekeeper для любых приложений без подписи,
а не признак битого файла. Проверить подлинность можно по контрольной сумме из `SHA256SUMS.txt` на странице загрузки.

## Как открыть (любой из способов)

1. **Правый клик** по приложению → **Открыть** → в диалоге ещё раз **Открыть**.
   Сработает один раз на машину, дальше приложение открывается двойным кликом.
2. **Системные настройки** → **Конфиденциальность и безопасность** → прокрутить вниз →
   кнопка **«Открыть всё равно»** рядом с уведомлением о блокировке → подтвердить.
3. **Терминал** (снимает карантин с уже установленного приложения):
   ```bash
   xattr -dr com.apple.quarantine "/Applications/EHOT Launcher.app"
   ```
   и открыть приложение двойным кликом.

## Как убедиться, что файл не подменён

```bash
shasum -a 256 ~/Downloads/EHOT-Launcher-0.5.1-osx-arm64.dmg
```
Сравните с суммой в `SHA256SUMS.txt` на странице загрузки или в релизе на GitHub.

## Что делаем дальше

- С версии 0.5.1 .app внутри .dmg **подписывается ad-hoc** (раньше подпись выполнялась после упаковки в .dmg и в образ не попадала — отсюда и «повреждён» на Apple Silicon).
- Полноценная подпись Developer ID + нотаризация (notarytool) требует Apple Developer Program; когда она будет оформлена, CI сможет подписывать и нотаризовать сборки автоматически.
- Windows собирается через Inno Setup без подписи — SmartScreen покажет похожее предупреждение («Подробнее» → «Выполнить в любом случае»).
