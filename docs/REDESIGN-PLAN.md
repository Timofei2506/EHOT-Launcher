## 1. Что уже есть (факты по коду)

**Стек:** Avalonia 12.1.6 · .NET 10 (SDK 10.0.403) · CommunityToolkit.Mvvm 8.4.2 · DI (Microsoft.Extensions.DependencyInjection) · SQLite (Storage) · ASP.NET Core Control Plane API (отдельный проект) · упаковка: Inno Setup (Windows), .dmg (macOS) · CI: build+test на Linux/Windows/macOS + publish 3 RID · тесты: `Launcher.Tests` + `Launcher.UI.Tests` (headless Avalonia, 101 тест в 0.2.2).

**Архитектура (не нарушать):** `UI → Game / Content / Network / Auth → Core → Platform`, API независимо. Модули: Auth (Microsoft device-code OAuth + локальные профили), Game (манифест Mojang, установка версий, лоадеры Fabric/Quilt/Forge/Neoforge/OptiFine, Java, запуск), Content (Modrinth; CurseForge через ключ), Network (комнаты/relay, экспериментальный TUN), Storage (SQLite-репозитории), Update (автообновление из `EHOT-Launcher-Releases`).

**Views сегодня (19):** Home, Play, Versions, ContentBrowse (+5 тонких обёрток Моды/Сборки/Текстуры/Шейдеры/Карты), Accounts, Downloads, GameNetwork, Import, Settings, About, MainWindow.
**Controls:** `RemoteImage` (иконки/обложки по URL с кэшем), `Skin3DView` (3D-предпросмотр скина, вращается мышью).
**Ассеты:** `ehot.ico/.icns/.png`, `ehot-512.png`, `ehot-logo-new.png` — старые фиолетово-синие градиентные лого.

## 3. Целевой вид (по концепт-доске)

**Окно:** кастомный titlebar; без акрила; тёплый тёмный фон; опциональное атмосферное воксель-фоновое изображение на главном экране (blur + затемнение, чтобы текст читался).

**Сайдбар (одна колонка, ~226px):** лого EHOT Launcher (оранжевый куб) → поиск/⌘K → пункты: **Играть · Моды и ресурспаки (единый раздел) · Галерея · Новости · Серверы · Сборки · Настройки** → внизу карточка аккаунта (ава, ник, тип). «О лаунчере» — внутри Настроек. Скрытые рабочие разделы (Аккаунт, Загрузки, Game Network, Импорт) открываются командами, но не занимают место в рельсе. Активный пункт — оранжевая подсветка.

**Главный экран «Играть»:** «Добро пожаловать!» + подзаголовок → выпадающий список версии (с поиском, типами release/snapshot, установленным статусом, ★ избранные) → чипы загрузчика (Vanilla / OptiFine / Forge / Fabric / NeoForge / Quilt) — недоступные для версии чипы видны, но задизейблены с подсказкой → **большая оранжевая кнопка «Играть»** со свечением → строка статуса установки/прогресс → справа крупная 3D-модель скина (вращается мышью) → под кнопкой карточка «Minecraft x.y.z · что нового · Подробнее →».

**Экран «Моды и ресурспаки»:** оранжевые pill-вкладки **Моды / Ресурспаки / Шейдеры / Датапаки**, строка поиска, фильтры (версия, загрузчик, сортировка), сетка карточек с обложкой, названием, автором, загрузками и кнопкой установки (как в концепте — карточки с крупными обложками). «Установленное» — переключатель вида. Страница проекта — боковая панель деталей (как сейчас, рестайл).

**Экран «Профиль»:** большой ава (пиксель-лицо скина или заглушка), ник `EHOT_ENOS14`, UUID с кнопкой копирования, «Изменить аватар», плашка статуса скина («Скин загружен · Сменить»), блок «Ваш профиль»: «Загрузить скин» (PNG 64×64/64×32), «Выбрать скин по нику», инфо-плашка «При использовании лицензионного аккаунта скин и UUID возьмутся автоматически».

**«Галерея»:** вкладки **Скриншоты / Видео**, сетка карточек из реальных папок `screenshots` (общая + каждая instance), полноэкранный просмотр, действия: открыть оригинал / копировать / удалить (с подтверждением) / открыть папку / сортировка по дате.

**«Новости»:** вкладки **Все / Обновления / События / Лаунчер**; карточки с картинкой, заголовком, датой, источником; «Подробнее» открывает статью; ссылка на оригинал обязательна.

**«Серверы»:** вкладки **Избранные / Популярные / Поиск**; строки: иконка, название, описание, онлайн (зелёный/серый индикатор), ★ в избранное; «+ Добавить сервер»; копирование адреса; редактирование порт/название/описание.

**«Сборки»:** сетка карточек-инстансов: название, версия+лоадер, размер на диске, кнопка «Играть», «…» (клон/правка/удалить); «Создать сборку» wizard в 1 экран.

**«Настройки»:** левый список **Основные / Minecraft / Интерфейс / Загрузка / Аккаунт** (как в концепте) + правая панель; переключатели (есть в Avalonia ToggleSwitch), селекты языка/темы/масштаба, RAM-слайдер, JVM-аргументы, пути.

**«О лаунчере»:** лого, версия/номер сборки, разработчики, ссылки (сайт/поддержка/GitHub), changelog, «Проверить обновления» (реальный UpdateManager).

**Экран «Запуск Minecraft…»:** полноэкранный сплэш: крупный маскот-енот, заголовок, оранжевая полоса прогресса, процент, совет дня (например «Используйте OptiFine для лучшей производительности»), кнопка «Отменить».

## 4. Что чего стоит (функциональная матрица)

| Раздел | Бэкенд | Статус |
|--------|--------|--------|
| Запуск / версии / лоадеры / Java / RAM | `Game.*`, `Platform.*` | ✅ готово, нужен только UX |
| Каталоги модов/сборок/текстур/шейдеров | `Content.*` (Modrinth; CurseForge по ключу) | ✅ готово, рестайл + единые вкладки |
| Новости (Mojang + лаунчер) | `IMinecraftNewsService` | ✅ есть сервис, нужен отдельный экран |
| Аккаунты / Microsoft OAuth / локальные / скины / UUID / 3D | `Auth.*`, `Skin3DView` | ✅ готово, рестайл экрана профиля |
| Обновления лаунчера | `Update.*` | ✅ готово, рестайл баннера |
| Загрузки | `Core.Downloads` + `DownloadsView` | ✅ готово, рестайл |
| **Галерея** | сканирование `.minecraft/screenshots` + `<instance>/screenshots` | ❌ новый сервис + экран |
| **Серверы** | сохранение/редактирование/избранное + Server List Ping (онлайн, игроки, версия) | ❌ новый модуль `ServerManager` |
| **Сборки (instances)** | `GameProfile` + `InstanceDirectory` уже есть | ⚠️ основа есть, нужны UI-экран и операции (RAM, лоадер, clone/delete, «Играть» из карточки) |
| **Датапаки** | `Content` (Modrinth type=datapack) | ⚠️ вероятно готов источник, нужна вкладка |
| **«Видео» в галерее** | записи отсутствуют в Minecraft | ❌ не делать (нет фейков), либо скрывать вкладку |
| **«Популярные серверы»** | официального каталога нет | ❌ не делать надуманного; «Популярные» = по собственным данным/курируемый список или убрать вкладку |
| Game Network (комнаты/TUN) | `Network.*` экспериментально | ⚠️ вне концепта — скрыт из рельса (доступен по команде `network`) |
| Импорт (из других лаунчеров) | `ImportView` есть | ⚠️ перенести в «Настройки → Основные → Импорт…» |

## 7. Этапы работ

- **Этап 0. Подготовка:** ветка `redesign`, установка .NET 10 SDK (или проверка через CI/GitHub Actions), снимок текущего состояния (`Не менять бэкенд`).
- **Этап 1. Токены и компоненты:** `Tokens.axaml` v2 (палитра, градиенты, тени, радиусы), `Controls.axaml` v2 (кнопки, поля, ToggleSwitch-стили, pill-вкладки, карточки, тосты, ProgressBar). Экраны не трогаем — получаем глобальный перекрас.
- **Этап 2. Каркас:** `MainWindow` — titlebar по концепту, двухколоночная структура, новый сайдбар (без правой колонки, без выпадающего «Каталога»), обновлённый счётчик уведомлений, баннер обновления из UpdateManager (рестайл), сохранение toast-системы.
- **Этап 3. «Играть»:** объединить Home+Play сценарий: версия с поиском/типами/★, чипы лоадеров, кнопка, статус/прогресс, карточка «Что нового» (из новостей Mojang), крупный Skin3DView справа. Старая техническая страница уходит в «Сборки» и «Настройки → Minecraft».
- **Этап 4. «Профиль»:** экран 1:1 по концепту (аватар-лицо, UUID+копи, «Изменить аватар», скин: загрузить / по нику, инфо-плашка), сайдбар-карточка аккаунта с лицом скина.
- **Этап 5. «Моды и ресурспаки»:** единый экран с оранжевыми вкладками (Моды/Ресурспаки/Шейдеры/**Датапаки** — если Modrinth отдаёт), фильтры+поиск, сетка обложек, «Установленное», панель деталей.
- **Этап 6. Новые разделы:** **Новости** (отдельная страница, 4 вкладки), **Сборки** (карточки-инстансы, wizard создания, clone/delete, «Играть» из карточки), **Галерея** (скан папок + просмотр), **Серверы** (ping, избранное, добавление).
- **Этап 7. Сплэш запуска:** полноэкранный экран «Запуск Minecraft…» с енотом, прогрессом, % и советом (окно/оверлей по выбранному паттерну окна).
- **Этап 8. «Настройки» + «О лаунчере»:** категории ТЗ, переключатели состояния, `О лаунчере` с changelog и реальными ссылками; автообновление рестайл.
- **Этап 9. Полиш и чистка:** hover/pressed, empty states, удаление мёртвого кода и старых ассетов, обновление `NavigationSmokeTests`/`UiSmokeTests` под новый рельс, проверка `-warnaserror`.
- **Этап 10. Проверка релиза:** `dotnet build -warnaserror`, `dotnet test` (101+), headless-скриншоты экранов, сборка установщиков, bump версии → 0.3.0; публикация релиза в `EHOT-Launcher-Releases` — **только с явного согласия**.

## 8. Риски / принципы

1. Ни одной фейковой кнопки: нереализуемое — скрыть или отключить с причиной (как сейчас с `CapabilityRegistry` — хороший паттерн, продолжим его).
2. Каждый этап — компилирующийся, тесты зелёные; бэкенд не ломаем.
3. Производительность: все изображения через `RemoteImage` + кэш; ленивая загрузка вкладок; ничего не грузим в конструкторах VM.
4. Русский язык интерфейса — сохраняем; тексты приводим к единому тону.
5. Не удаляем фичи ТЗ; экспериментальное прячем, не удаляем код.
6. Сеть: новости/пинг/каталоги — с таймаутами и понятными ошибками (как сейчас).
