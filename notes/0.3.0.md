Большой редизайн: тёмная оранжевая тема, новый рельс разделов, новые разделы.

**Новый облик**
- Тёмная тема с фирменным оранжевым акцентом (#F07832/#FF9A45), плоские карточки, обновлённые компоненты и иконки приложения.
- Новый рельс: Играть · Моды и ресурспаки · Галерея · Новости · Серверы · Сборки · Настройки.
- Новый главный экран: выбор версии (релизы/снапшоты) прямо на странице, чипы лоадеров, установка при нажатии «Играть», честный прогресс и крупный 3D-скин.

**Единый каталог**
- Моды, Модпаки, Ресурспаки, Шейдеры и Датапаки в одном разделе с вкладками, установка через Modrinth, реальные иконки проектов.

**Новые разделы**
- Галерея: реальные скриншоты .minecraft и инстансов, превью, полноэкранный просмотр, открытие в папке, удаление с подтверждением.
- Новости: официальные публикации Mojang Java Edition, просмотр статей внутри лаунчера.
- Серверы: свой список серверов, Minecraft Server List Ping (онлайн/игроки/версия/MOTD/задержка), копирование адреса, добавление и удаление.
- Сборки: профили-инстансы — выбор активной сборки, клон, избранное, удаление записи (файлы остаются), открыть папку.

**Настройки**
- «О лаунчере» перенесена внутрь: версия, среда выполнения, «Проверить обновления», ссылки (GitHub/релизы/сообщить об ошибке), правовое уведомление.
- Аккаунт, Загрузки, Game Network и Импорт доступны как скрытые рабочие разделы.

**Проверки**
- `dotnet build -warnaserror` — чисто; smoke-тесты зелёные на ubuntu/macOS/windows.

Установщики: Windows x64, macOS Apple Silicon, macOS Intel.
