Исправление запуска на macOS.

**macOS: «файл повреждён и его не удалось открыть»**
- Причина: ad-hoc подпись .app выполнялась ПОСЛЕ упаковки в .dmg, поэтому в образ попадал неподписанный бандл. На Apple Silicon такой бандл система отказывается запускать.
- Исправлено: .app подписывается ad-hoc до создания .dmg, подпись проверяется `codesign --verify --deep --strict`. Неподписанный .app больше не попадает в релиз.
- Полноценная подпись Developer ID + нотаризация по-прежнему требует Apple Developer Program (её нет) — поэтому первый запуск может потребовать «правый клик → Открыть», инструкция на сайте и в docs/MACOS-GATEKEEPER.md.

Также: заметки на странице загрузки объясняют оба способа открытия.

Установщики: Windows x64, macOS Apple Silicon, macOS Intel.
