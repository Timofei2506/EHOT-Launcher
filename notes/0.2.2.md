Оптимизация и импорт: OptiFine, моды производительности, импорт из чужих лаунчеров.

**OptiFine** (проблема 5)
- Список версий OptiFine для каждой версии Minecraft через bmclapi2 с зеркалом optifine.net.
- Установка патчем: патчит оригинальный клиент-jar через `java -cp optifine.jar optifine.Patcher`, библиотеки OptiFine и launchwrapper-of подменяют загрузчик.
- Запуск OptiFine-версии через `net.minecraft.launchwrapper.Launch` с `--tweakClass optifine.OptiFineTweaker`.

**Моды оптимизации** (проблема 6)
- Детекция железа: `GraphicsDetector` читает видеокарту (Windows реестр / WMI, macOS `system_profiler`, Linux `lspci`) и классифицирует в Low/Medium/High (Apple Silicon → High).
- Подбор модов под профиль: sodium, embeddium, iris, indium, entityculling, lithium, ferrite-core, krypton, modernfix — только проверенные, только для Fabric/Forge/NeoForge.
- Карта в разделе «Моды»: честный текст при отсутствии профиля или ванильном профиле («модам нужен лоадер»), кнопка «Установить всё» ставит весь набор в текущий профиль.

**Импорт из чужих лаунчеров** (проблема 10)
- Новый раздел «Импорт» в меню «Система»: пользователь сам указывает путь к чужому `.minecraft`, лаунчер ничего не читает автоматически.
- Переносятся только пользовательские данные: миры (saves), скриншоты, пакеты ресурсов. Моды — по желанию с предупреждением про лоадер.
- Версии, библиотеки, логины и конфиги исходного лаунчера не трогаются — честно указано в списке пропускаемого.
- Создаётся новый инстанс, который появляется в «Играть».

**Остальное из десятки**
- Ускорение запуска: «Играть» показывает только реально скачанные версии.
- Сохранение прогресса загрузки при закрытии.
- Единый размер кнопок окон, структура левого меню, установка без профиля, 3D-превью скина, аккаунты/скины UX.

**Проверки**
- `dotnet build EHOT.Launcher.slnx -warnaserror` — чисто.
- `dotnet test` — 101/101.

Установщики: Windows x64, macOS Apple Silicon, macOS Intel.
