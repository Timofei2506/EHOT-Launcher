Почему система предупреждает. Сборки пока без коммерческой подписи, поэтому Windows SmartScreen показывает «неизвестный издатель», а macOS просит подтвердить запуск. Это не вирус, а отсутствие платного сертификата. На macOS: правый клик по приложению → «Открыть», или команда xattr -dr com.apple.quarantine "/Applications/EHOT Launcher.app". Подпись и нотаризация — в планах.

Частые вопросы

Это пиратский лаунчер?

Нет. Для игры на официальных серверах нужна приобретённая копия Minecraft и вход через Microsoft. EHOT Launcher не обходит и не ослабляет лицензионную защиту. Офлайн-профили предназначены для локальной игры и явно помечены как офлайн.

Куда лаунчер ставит игру и настройки?

Игра — в отдельную папку профиля (по умолчанию рядом с данными лаунчера), настройки и база — в системную папку приложения. В «Настройках» можно указать свой путь к папке Minecraft.

Почему Game Network иногда пишет «ограничено»?

Полноценный сетевой туннель требует подписанного драйвера на Windows и Network Extension на macOS. Без них лаунчер работает через прямое соединение или relay и честно сообщает об ограничении, а не изображает подключение.

Моды и сборки — откуда?

Из официального API Modrinth. CurseForge работает только если у вас есть собственный API-ключ: лаунчер не содержит и не может содержать чужой ключ.

Есть ли Linux?

Ядро лаунчера кроссплатформенное, сборка под Linux используется в автотестах. Пользовательский установщик для Linux пока не публикуется.
